Build it. Send it. Understand it.

A task tracker that shows what happens behind every button. Start the server, paste your local token, and make your first API request.

01 / CONNECT

Who is making the request?

Your token identifies your API client. The server only returns tasks owned by that identity.

The token stays in this page's memory. Reloading clears it. Never paste a production credential into a learning app.

Ready when you are.
02 / CREATE

Turn an idea into a record.

This sends POST /v1/tasks with JSON. A successful creation returns 201 and a Location header pointing to your new task.

Try a validation error

Send the wrong data type and inspect the 422 response. This deliberately sends done as a string instead of a boolean.

03 / READ, UPDATE, DELETE
